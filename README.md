# RackManager IA

Sistema interno de gestão de infraestrutura (inventário, racks, IPAM, VLANs e conectividade),
inspirado nas funcionalidades do RackTables e construído com Claude Code.

- Plano do projeto: [`docs/PLANO_PROJETO.md`](docs/PLANO_PROJETO.md)
- Stack: PHP / Laravel / Livewire / MySQL / Apache (VirtualHost + PHP-FPM) — sem Docker.
- Deploys: somente com autorização do coordenador técnico.
